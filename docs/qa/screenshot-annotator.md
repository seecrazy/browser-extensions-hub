# screenshot-annotator manual QA

Run after `pnpm build` before tagging a release.

- [ ] Open a page and click Capture visible area.
- [ ] Confirm annotate page opens with screenshot.
- [ ] Draw rectangle, arrow, text, and brush.
- [ ] Press Escape during rectangle drag.
- [ ] Press Ctrl/Cmd+Z and confirm undo.
- [ ] Copy image and paste into an editor.
- [ ] Download PNG.
- [ ] Confirm screenshot is removed from session storage after load.

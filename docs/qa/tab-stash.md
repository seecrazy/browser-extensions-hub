# tab-stash manual QA

Run after `pnpm build` before tagging a release.

- [ ] Open at least three non-browser pages.
- [ ] Stash tabs with a custom group name.
- [ ] Confirm tabs close and group appears.
- [ ] Search by title and URL.
- [ ] Restore one tab and restore all tabs.
- [ ] Rename and delete a group.
- [ ] Export JSON, delete data, then import JSON.

## Result

- [ ] Chrome passed
- [ ] Firefox passed
- [ ] No console errors
- [ ] Permissions match the listing

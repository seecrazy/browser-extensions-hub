# Reading Progress Lite — Chrome Web Store listing

## Name

Reading Progress Lite

## Short description

Show how far you have read on the current page.

## Detailed description

Reading Progress Lite adds a thin, adjustable progress bar to the current page. Choose its color, height, and position. Preferences are stored per site and all processing is local.

## Single purpose

Show a scroll progress bar on web pages.

## Permission justifications

- `activeTab`: activeTab grants access only after the user opens the extension popup.
- `scripting`: scripting injects the progress bar into the current tab after explicit activation.
- `storage`: storage keeps per-site color, height, position, and offset preferences on this device.

# Quick Translate — Firefox Add-ons listing

## Name

Quick Translate

## Summary

Select text and get a quick translation.

## Description

Quick Translate activates only for the tab you choose. Select text and a lightweight bubble shows the translation. It supports copy, timeout, caching, and right-to-left languages. Selected text is sent to Google Translate to produce the translation.

## Permission justification

activeTab and scripting let the extension add the selection bubble only after you click Enable on this tab. storage remembers your target language.

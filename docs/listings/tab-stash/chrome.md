# Tab Stash — Chrome Web Store listing

## Name

Tab Stash

## Short description

Stash tabs, free memory, and restore them later.

## Detailed description

Tab Stash saves tabs from the current window into a local, named group and closes the originals. You can search stashed tabs, restore one tab or a whole group, and export or import your stash as JSON.

## Single purpose

Save tabs from the current window into local named groups and restore them later.

## Permission justifications

- `tabs`: tabs reads titles and URLs, closes stashed tabs, and reopens saved tabs in response to user actions.
- `storage`: storage keeps stashed tab groups on this device.

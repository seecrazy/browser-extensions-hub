# New Tab Dashboard Lite — Chrome Web Store listing

## Name

New Tab Dashboard Lite

## Short description

A clean local dashboard for time, todos, and shortcuts.

## Detailed description

New Tab Dashboard Lite replaces the new tab page with a quiet, local dashboard. Track simple todos, open your favorite sites, and keep everything on your device. It does not change your search engine, insert news feeds, or show ads.

## Single purpose

Provide a local new-tab dashboard for time, todos, and shortcuts.

## Permission justifications

- `storage`: storage keeps todo entries and shortcut definitions on this device.

# Font Switcher Lite — Chrome Web Store listing

## Name

Font Switcher Lite

## Short description

Use local Kai, Song, Hei, or FangSong fonts on the current page.

## Detailed description

Font Switcher Lite applies locally installed CJK fonts to the page you are viewing. Preview Kai, Xingkai, Song, Hei, and FangSong styles before choosing one, and keep your default and per-site preferences on your device. It does not download fonts, show ads, or collect analytics.

## Single purpose

Apply a locally installed CJK font to the current web page.

## Permission justifications

- `activeTab`: activeTab grants access only after the user opens the popup.
- `scripting`: scripting injects the content script that applies the selected font to the current page.
- `storage`: storage keeps default and per-origin font preferences on this device.

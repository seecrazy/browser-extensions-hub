# Privacy Cleaner Lite — Chrome Web Store listing

## Name

Privacy Cleaner Lite

## Short description

Clear storage data for the current site only.

## Detailed description

Privacy Cleaner Lite gives you a manual button to remove cookies, local storage, IndexedDB, and optionally cache for the site you are viewing. Cleanup is limited to one origin at a time and only runs when you click it.

## Single purpose

Clear storage data for the current website only when the user requests it.

## Permission justifications

- `activeTab`: activeTab identifies the origin of the current tab after the user opens the popup.
- `browsingData`: browsingData removes the selected storage types for the current origin only.
- `storage`: storage keeps the user's cleanup preferences on this device.

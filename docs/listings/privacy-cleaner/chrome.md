# Privacy Cleaner Lite — Chrome Web Store listing

## Name

Privacy Cleaner Lite

## Short description

Clear storage data for the current site only.

## Detailed description

Privacy Cleaner Lite gives you a manual button to remove cookies, local storage, IndexedDB, and optionally cache for the site you are viewing. Cleanup is limited to one origin at a time and only runs when you click it.

## Permission justification

activeTab identifies the current site origin. browsingData removes selected storage data for that origin only. storage remembers your cleanup preferences.

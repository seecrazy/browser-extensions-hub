# Hub Template — Firefox Add-ons listing

## Name

Hub Template

## Summary

A minimal WXT extension template.

## Description

Hub Template is the starter extension used by contributors to Browser Extensions Hub. It contains a popup, a background service worker, typed message contracts, namespaced storage, and the standard build pipeline.

## Permission justification

storage is used to keep template settings local to the browser. The extension does not read page content and does not connect to a network service.

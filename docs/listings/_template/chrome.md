# Hub Template — Chrome Web Store listing

## Name

Hub Template

## Short description

A minimal WXT extension template.

## Detailed description

Hub Template is the starter extension used by contributors to Browser Extensions Hub. It contains a popup, a background service worker, typed message contracts, namespaced storage, and the standard build pipeline.

## Single purpose

Provide a minimal starter extension template for plugin development.

## Permission justifications

- `storage`: storage keeps template settings local to the browser.

# Security Policy

## Supported versions

Security fixes target the latest `main` branch and released extension versions listed in GitHub Releases.

## Reporting

Please report suspected vulnerabilities privately through GitHub Security Advisories when available. Include:

- affected plugin and version;
- reproduction steps;
- browser and OS;
- whether the issue requires a crafted page or malicious extension;
- expected and observed behavior.

Do not include real credentials or private browsing data in reports.

## Scope

The repository is intentionally local-first:

- no accounts;
- no telemetry;
- no cloud storage;
- no broad host permissions by default.

Quick Translate sends selected text to Google Translate. This is disclosed in its listing and privacy summary.
